PERSONALPRO - NEXT STEPS FOR DEPLOYMENT

The complete PersonalPro SaaS application has been built and is ready for use.
Follow these steps to get it running:

STEP 1: PREPARE YOUR FIREBASE PROJECT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. Go to https://console.firebase.google.com
2. Create a new project (or use existing)
3. Go to Project Settings
4. Copy the web app config values

STEP 2: UPDATE FIREBASE CONFIGURATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. Open: src/firebase.js
2. Replace these placeholders with your Firebase values:
   - YOUR_API_KEY
   - YOUR_PROJECT.firebaseapp.com
   - YOUR_PROJECT_ID
   - YOUR_PROJECT.appspot.com
   - YOUR_SENDER_ID
   - YOUR_APP_ID

STEP 3: ENABLE FIREBASE SERVICES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
In Firebase Console:

Authentication:
  → Go to Authentication → Sign-in method
  → Enable "Email/Password"
  → Click Save

Firestore Database:
  → Go to Firestore Database
  → Click "Create database"
  → Select "Start in test mode"
  → Choose your region
  → Click Enable

STEP 4: SET FIRESTORE SECURITY RULES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
In Firestore Database → Rules, paste this:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId} {
      allow create: if request.auth.uid == userId;
      allow read, write: if request.auth.uid == userId;
      
      match /students/{document=**} {
        allow read, write: if request.auth.uid == userId;
      }
      
      match /records/{document=**} {
        allow read, write: if request.auth.uid == userId;
      }
      
      match /payments/{document=**} {
        allow read, write: if request.auth.uid == userId;
      }
    }
  }
}

STEP 5: INSTALL DEPENDENCIES
━━━━━━━━━━━━━━━━━━━━━━━━━━━
Run in the project folder:
  npm install

STEP 6: RUN DEVELOPMENT SERVER
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Run:
  npm run dev

Open http://localhost:5173 in your browser

STEP 7: CREATE YOUR ACCOUNT
━━━━━━━━━━━━━━━━━━━━━━━━━
1. Click "Registrar" tab
2. Enter your email
3. Enter password (6+ characters)
4. Click "Registrar"
5. You're logged in!

STEP 8: ADD YOUR FIRST STUDENT
━━━━━━━━━━━━━━━━━━━━━━━━━━
1. Go to "Alunos" tab
2. Click "+ Novo"
3. Fill in:
   - Name: Student name
   - Price/Class: 70 (or your price)
   - Schedule: Click time slots (e.g., "Segunda 06:00")
4. Click "Salvar"

STEP 9: TRACK ATTENDANCE
━━━━━━━━━━━━━━━━━━━━━━
1. Go to "Registro" tab
2. Select a date
3. Click "Presente" or "Ausente" for each class
4. Changes save automatically

STEP 10: VIEW FINANCIAL REPORT
━━━━━━━━━━━━━━━━━━━━━━━━━━
1. Go to "Relatório" tab
2. Select month and year
3. See:
   - Gross revenue
   - Gym fee (R$21 per class)
   - Net income
   - Per-student breakdown

READY FOR PRODUCTION?
━━━━━━━━━━━━━━━━━━━

  npm run build

Deploy to:
