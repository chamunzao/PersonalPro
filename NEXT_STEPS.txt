PERSONALPRO - PROXIMOS PASSOS

Estado atual:
- App em MVP avancado / beta utilizavel.
- Firebase real configurado.
- Build de producao funcionando.
- Central de Acoes criada na aba Alertas.

COMO RODAR

1. Instalar dependencias
   npm install

2. Rodar localmente
   npm run dev

3. Gerar build
   npm run build

O build atual passa. O unico aviso conhecido e o bundle JavaScript grande, que deve ser tratado depois com code splitting.

PROXIMA VALIDACAO DE VALOR

1. Entrar pela conta demo ou por uma conta real.
2. Cadastrar de 5 a 10 alunos.
3. Criar horarios fixos e algumas aulas avulsas/reposicoes.
4. Executar uma aula pela aba Aula.
5. Marcar presencas e faltas pelo Inicio, Agenda, Registro e Alertas.
6. Registrar pagamentos e pacotes.
7. Usar Alertas como Central de Acoes:
   - enviar WhatsApp;
   - marcar pagamento como pago;
   - resolver aula sem registro.
8. Conferir se o Relatorio fecha com a expectativa financeira.

O QUE MAIS GERA VALOR AGORA

1. Teste piloto real no celular.
2. Ajustar qualquer atrito encontrado nos fluxos de aula, cobranca e renovacao.
3. Corrigir textos com acentos quebrados.
4. Criar testes automatizados para cobranca, pacotes, agenda e alertas.
5. Aplicar code splitting para reduzir o bundle.
